# rust-agent

Rust workspace for the `rust-agent` project.

## Workspace Members

- [`agent-core`](agent-core/) - Core agent library.
- [`agent-provider`](agent-provider/) - Provider implementations.
- [`agent-gui`](agent-gui/) - Tauri desktop GUI using React, TypeScript, Vite, and Tailwind CSS.

## Build

```bash
cargo build
```

## Test

```bash
cargo test
```
